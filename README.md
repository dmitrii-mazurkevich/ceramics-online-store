# Online store for ceramics and tea

A ceramics and tea shop that was losing orders in Instagram messages.

**Live:** https://dmitrii-mazurkevich.github.io/ceramics-online-store/

![Online store for ceramics and tea](preview.png)

## Built with

HTML, CSS, JavaScript, localStorage, Schema.org Product. Static site without a build step: open `index.html` or publish the folder to any hosting.
English and Russian versions with a language switcher, layout for phones and desktops.
